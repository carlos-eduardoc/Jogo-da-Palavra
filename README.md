# 🎯 Jogo da Palavra

Projeto simples em Python inspirado no clássico jogo da forca, onde o jogador precisa adivinhar uma palavra secreta digitando letras.

Repositório:  
https://github.com/Carlos-coder-c/Jogo-da-Palavra

---

## 📌 Objetivo

O objetivo do jogo é descobrir a palavra secreta digitando letras individuais.  
A cada tentativa, o sistema revela as letras corretas já descobertas e mantém ocultas as restantes.

Palavra secreta atual:
python

---

## 🚀 Como Executar

### 1️⃣ Requisitos
- Python 3.x instalado

### 2️⃣ Executar o jogo

```bash
python nome_do_arquivo.py
🧠 Funcionamento
O jogo roda em loop infinito (while True)
A cada iteração:
O usuário digita uma letra
O sistema verifica se ela pertence à palavra secreta
Exibe o progresso atual com * nas letras não descobertas
O jogo termina quando não houver mais * no resultado
